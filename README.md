# This project has moved to Omafan

Development continues at **[kartikkabadi/omafan](https://github.com/kartikkabadi/omafan)**.

Omafan is the maintained project for Apple Silicon fan control and thermal
monitoring on Omarchy. It includes independent Linked/Separate profiles,
persistent settings, supervised recovery and the updated interface.

- [Install Omafan](https://github.com/kartikkabadi/omafan#install)
- [Migrate an existing installation](https://github.com/kartikkabadi/omafan/blob/main/docs/MIGRATION.md)
- [Report a problem](https://github.com/kartikkabadi/omafan/issues)

This repository is retained as a historical archive. Its code and branches are
preserved; use Omafan for future updates. The new repository retains the complete
Git history and original attribution.
